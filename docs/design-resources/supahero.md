# Supahero — Knowledge File

> Research date: 2026-09-13. Verified against supahero.io and the 
> screensdesign transition banner. Anything not verified is labeled.

## Resource Overview

Supahero is a **curated inspiration gallery of website hero sections**. It is
a library/reference of screenshots of famous SaaS and consumer-brand hero
sections (Stripe, Linear, Figma, Resend, Apple, Tesla, Ramp, BMW, etc.), each
with a preview screenshot and a "Visit Website" link.

At research time, Supahero announced it is **now part of screensdesign**
("supahero is now part of screensdesign … the biggest UX app library in the
world") — the same banner appears site-wide.

## Official URL

- https://supahero.io
- https://supahero.io/templates (Framer templates section)
- https://supahero.io/pricing (advertising rates, not licensing)
- screensdesign: the parent product

## Resource Type

- **Visual inspiration gallery** (hero-section screenshots)
- **Framer template listings** (portfolio, agency, e-commerce templates such as
  Foliofy, Dashfolio Neo, Folioblox)
- Not a component library, not a code generator, not an installable package.

## What It Provides (verified)

1. ~200 hero screenshots, each with screenshot preview + external link.
2. A **Templates** section promoting "Beautiful, ready-to-use Framer templates"
   (Framer-oriented).
3. The **pricing page is advertising**, not licensing: Featured Badge $79/30d,
   Premium Spot $149/30d, Featured Spot $279/30d — these are fees for being
   featured on the site (verified via the site and the Gumroad sales page).

## Technologies Used

- Could **not be verified**: no React/Next.js/HTML output, no code snippets, no
  export mechanism, no installable anything were exposed on the pages fetched.
- The template ecosystem is **Framer-oriented** (site targets Framer users).

## CAM LABS Use Cases (candidate, NOT implemented)

- **Visual reference only.** The hero list skews SaaS/consumer brands; no
  industrial/manufacturing heroes were evident in the inspected entries.
- Potentially useful as a *composition reference* for future landing/hero
  iterations (headline + visual stage + CTA + trust bar layouts), to be
  reimplemented in the existing CAM LABS style.
- **Nothing is technically reusable** in the React + Vite + TypeScript stack.

## Limitations

   screensdesign.
